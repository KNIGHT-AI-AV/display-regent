Display Regent — Windows preview

Install: run the Setup.exe. The app installs only for your Windows user;
there is no administrator prompt and no separate runtime to download.
Portable: extract the ZIP to a normal folder and run DisplayRegent.exe.

Click the tray icon or press Ctrl + Alt + M to open the compact tray widget.
The glass popup fades in above the system tray. Click a line-art monitor box
to switch that output on or off. Hover a box to crossfade its number into its name.
Click a screen again within 20 seconds to keep the switch, or press Escape to undo.
Preset boxes 1, 2 and 3 recall your first three saved scenes.
There are no checkbox or action-button rows in the widget.
Choose Full panel for new presets, advanced layout, settings or troubleshooting.
Select a numbered frame or a numbered selector to edit that monitor.
Use the checkbox to enable or disable a display. At least one must stay on.
Set the primary display, choose a resolution, or drag frames to arrange them.
Display edges snap together. Arrange and Stack provide quick layouts.
Use Desktop mode to extend or mirror another connected display.
Mirrored monitors share one desktop frame with individual numbered controls.
Resolution determines the diagram's scale; it is not a measurement in inches.

Apply layout validates the draft with Windows and then switches outputs.
Click Keep changes within 20 seconds. Otherwise the old layout is restored.
A separate process also attempts recovery if the main app closes or crashes.
Save scene stores this draft, including screens that are off. A shortcut
can be assigned with Ctrl + Alt + 1–9. Scene buttons apply with recovery.
Scene shortcuts report conflicts instead of stealing another app's shortcut.

Settings has two toggles: stay on top, and start in the tray at sign-in.
Choose Light or Dark from the top bar. Close hides the panel; Quit in the
tray exits the app. Uninstall through Windows Installed apps.

This preview is not Authenticode signed. Windows may show a publisher or
SmartScreen warning. Do not treat an unsigned preview as a trusted signed
release. Checksums identify release files; they do not certify the publisher.

Supports Windows 10/11 with a WDDM graphics driver in the local desktop
session. The graphics driver decides which layouts and timings are supported.
No promise covers every dock, GPU, remote session or physical connector.
Disabling an output removes its Windows desktop signal; it does not turn
off monitor power, change a monitor's input source, or prevent that monitor
from automatically selecting another device. HDR and refresh rate editing
are not included. Existing timings are retained where the route permits it.

No network calls, account, telemetry, cloud service or external runtime.
Settings and presets stay in %LOCALAPPDATA%/DisplayRegent.
