# Contributing

Display Regent is a free MIT-licensed Knight AI+AV project. Issues, forks and
pull requests are welcome. Maintainers approve merges and publish releases.

Before submitting, run the Windows build and layout checks in the README.
For display bugs, report Windows version, GPU/driver, connection type, mirror
or extend mode, and expected versus observed behavior. Redact local file paths
and monitor device identifiers from diagnostics. Hardware switching tests
temporarily change display configuration; close sensitive work first.

Keep the desktop app offline, preserve recovery, avoid new library dependencies
unless they solve a concrete problem, and respect reduced motion and both themes.
Do not commit signing material, preferences, recovery snapshots or private data.

The customer website is KnightAIAV.com. GitHub hosts source and release artifacts;
this project does not use GitHub Pages. All releases are owned by KNIGHT-AI-AV.
